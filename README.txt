My Fishing Life (MFL) Version 1.2

ホームの日付アイコンから開く、シンプルな釣行予定カレンダーを追加。
日付をタップするだけで「釣りに行く／行かない」を切り替えられます。

My Fishing Life Version 1.0

ファイル内容
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js

使い方
1. フォルダ内のファイルを同じ場所に置きます。
2. GitHub Pages または Netlify にアップロードします。
3. iPhoneのSafariで公開URLを開きます。
4. 共有メニューから「ホーム画面に追加」を選ぶとアプリ風に使えます。

初期版の機能
- 釣行開始
- 釣果登録（写真、魚種、サイズ、匹数、釣り方、持ち帰り/リリース）
- 魚図鑑
- 持ち物チェック
- 端末内自動保存
- オフライン対応の基本構成

注意
記録はブラウザ内に保存されます。SafariのWebサイトデータを削除すると記録も消えます。


Version 1.1 追加機能
