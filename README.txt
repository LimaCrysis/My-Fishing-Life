MY FISHING LIFE v1.5 - My Tackle / Ocean Rank

追加内容
- My Tackle を独立メニューとして追加
- タックル名、ロッド、リール、ラインを登録
- 釣果登録時に使用タックルを選択
- タックルごとの累計釣果を自動集計
- Ocean Rank を追加
  0 石 / 1 貝殻 / 50 サンゴ / 100 ヒトデ / 300 ヤドカリ
  500 海の仲間 / 1000 イルカ / 3000 ウミガメ / 5000 クジラ / 10000 海王
- 次のランクまでの匹数を表示
- ホームから My Tackle へ移動可能

既存の釣行予定・釣行記録・魚図鑑・持ち物データは localStorage をそのまま使用します。
