# MFL 一般海釣り場・調査アーカイブ

このディレクトリは、MFL本番データへ反映する前の**調査証跡専用**です。PWA本体からは読み込みません。

## ファイル
- `sea-fishing-research.json`：候補地点、確認事項、ソース、判断状態。未確認は null とし、推測で埋めない。
- `article-ledger.json`：一度確認した記事URLの重複排除台帳。累計調査率は分母確定まで算出しない。
- `daily/`：日次調査の記録（必要に応じて日付別に追加）。

## 運用ルール
1. 公式・自治体・港湾・公園を優先。民間の現地記事は現地状況の証拠であって公式許可とは区別。
2. `new_candidate`, `existing_supplement`, `hold`, `excluded`, `temporarily_closed`, `needs_verification` を区別。
3. 既存地点は差分のみ記録する。本番反映済みと未反映は別管理。
4. 各情報に確認日と根拠URLを付ける。閉鎖・規制は再確認の必要性を残す。
5. 日次自動調査が本当にGitHubへ書き込めたかはコミットSHAで検証する。チャット報告のみを保存完了とみなさない。
6. 複数タスクから同じJSONを同時編集しない。更新時は最新SHAを取得して差分を統合する。
7. 過去の全調査履歴は未移行。台帳の初期件数を累計調査済み件数と誤解しない。
